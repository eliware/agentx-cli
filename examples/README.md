# Examples

Return to the [repository README](../README.md).

This directory contains runnable examples for AgentX CLI. Each example lists prerequisites, commands, and expected results; use placeholders for credentials and never put secrets in example files.

## Basic CLI smoke example

- [basic.mjs](basic.mjs): print a short reminder of the README-guided CLI example; run with `node examples/basic.mjs` on Node.js 26.x.

## One-shot request

- [One-shot request](one-shot/README.md): send a single prompt and print its response.
